# To-Do App

A simple To-Do App built using Kotlin and Jetpack Compose.

## Features

- Add Tasks
- Delete Tasks
- Modern UI
- Jetpack Compose

## Tech Stack

- Kotlin
- Jetpack Compose
- Material 3

## Installation

1. Clone the repository

```bash
git clone https://github.com/IronMan0208/To-Do-App.git
```

2. Open in Android Studio
3. Run the project
